# ClipCraft Backend

Backend service for the ClipCraft Web Suite.

## Project

ClipCraft is a browser-based video editing platform.

## Backend Stack

- PostgreSQL
- JSONB
- FFmpeg
- ffprobe
- JWT Authentication
